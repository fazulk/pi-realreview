Verdict

Request changesTwo actionable findings remain after checking five candidates against the code. The cache key can mix results between workspaces, and a rejected request stays cached.

Findings

↩ ReconciliationP1R1Include the workspace in the cache key

src/cache.ts:42–48

The cache is keyed only by documentId, although document IDs are unique within a workspace. After switching workspaces, a request for the same ID can return the previous workspace’s document.

Key entries by both workspaceId and documentId, and add a regression case with matching IDs in two workspaces.

↩ ReconciliationP2R2Evict rejected promises so requests can retry

src/cache.ts:63–71

The pending promise is stored before the request completes. If the request rejects, that rejected promise remains in the cache and every later attempt fails immediately.

Remove the entry on rejection, then verify that a second request succeeds after a transient failure.
